Integration

Up and running in 4 steps

Connect CBA-MCP to Cursor, Claude Desktop, or any MCP-compatible agent in minutes.

1

Clone and install

Requires Node.js 20+. Clone the repo and install dependencies.

bash 
git clone git@github.com:rasheedcalgary/cbfa-mcp.git
cd cbfa-mcp
npm install
2

Configure server credentials

Copy the example env file and fill in the server-side infrastructure credentials. These are operator-managed — users never touch this file.

.env 
# Transport: "stdio" (default) or "http"
TRANSPORT=stdio

# Admin Panel base URL
ADMIN_PANEL_DOMAIN=https://api.trainerize.com

# Bitrise (for build action tools)
BITRISE_TOKEN=your-bitrise-token

# AWS / S3 (CBA CSV data layer)
AWS_ACCESS_KEY_ID=your-key-id
AWS_SECRET_ACCESS_KEY=your-secret
AWS_REGION=us-east-1
S3_BUCKET=your-bucket
S3_KEY=path/to/cba_apps_dump.csv
3

Build the server

Compiles TypeScript to an optimised ESM bundle in dist/.

bash 
npm run build
# ⚡️ Build success in ~25ms
4

Add to your agent config

Each user adds this snippet to their ~/.cursor/mcp.json (or claude_desktop_config.json). The ADMIN_PANEL_API_KEY is the only value each user needs to supply — all server-side credentials are pre-loaded from .env.

~/.cursor/mcp.json 
{
  "mcpServers": {
    "cba-mcp": {
      "command": "npm",
      "args": ["--prefix", "/path/to/cbfa-mcp", "start"],
      "env": {
        "ADMIN_PANEL_API_KEY": "your-api-key"  ← only user-supplied value
      }
    }
  }
}

Restart Cursor. A green dot in Settings → MCP confirms the server is connected.

Capabilities

10 tools, zero boilerplate

Every tool validates authentication, streams structured output, and returns clear error messages when credentials are missing.

📖 Read tools — require ADMIN_PANEL_API_KEY

list_apps
List all CBA apps with optional filter by type — enterprise, studio, pro, or abc.
READ
get_app_info
Full details for one app — merges CSV registry with live Admin API data including push cert expiry, theme config, and store links.
READ
get_ios_status
iOS App Store version, store status (ReadyForSale / None), and Apple account info for a specific app.
READ
get_android_status
Google Play version, store state, and Play account info for a specific app.
READ
get_app_last_updated
Last iOS and Android publish dates with days-ago labels and freshness rating (fresh / recent / aging / stale).
READ
get_pending_apps
Apps stuck in publish queues — PendingPublishList, PendingAppleSubmission, PendingAppleAgreement, or missing Google Play key.
READ
get_stale_apps
Apps not updated within a configurable threshold (default 180 days), filterable by type and platform.
READ
get_build_queue
Live CI build queue state — ReadyToBuild, Building, Built, Failed — for iOS or Android via the Admin API.
READ
query_apps
Flexible AND-filter report — combine ios_version, android_version, status, ios_store_status, app_type, and business_type in one query.
READ

⚡ Action tools — require BITRISE_TOKEN or Jenkins credentials

trigger_app_build
Trigger an iOS or Android build on Bitrise or Jenkins for a given app. Returns build ID and queue URL.
ACTION
get_build_status
Poll build state, duration, and log URL for a running or completed build.
ACTION

Transports

Works with every MCP client

Switch transport modes with a single environment variable. No code changes required.

📡 stdio default

The agent spawns the server as a subprocess and communicates over stdin/stdout. Zero network config — just add the mcp.json snippet and go.

Cursor Claude Desktop MCP Inspector VS Code (Copilot) 
TRANSPORT=stdio # default
npm start

🌐 HTTP remote

Exposes Streamable HTTP (POST /mcp) and legacy SSE (GET /sse) endpoints. Deploy to any server and connect remotely.

Claude.ai OpenAI Agents SDK LangChain n8n Custom agents 
TRANSPORT=http npm start
# Server on http://localhost:3000
