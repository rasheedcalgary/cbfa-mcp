Capabilities

11 tools, zero boilerplate

Every tool validates auth, redacts sensitive values from logs, and returns actionable error messages when credentials are missing.

📋
list_apps
READ

List all CBA apps in the registry, with optional filter by type — enterprise, studio, pro, or abc.

🔍
get_app_info
READ

Full details for one app — combines CSV registry data with live Admin API: push cert expiry, store links, theme config.

🍎
get_ios_status
READ

iOS App Store version, store state, iOS membership status (AgreementIsMissing), and Apple account.

🤖
get_android_status
READ

Android version, Google Play store state, and Play Store account info.

📅
get_app_last_updated
READ

Last iOS and Android publish dates with days-ago labels and a freshness rating (fresh / aging / stale).

⏳
get_pending_apps
READ

Apps stuck in queues — PendingAppleSubmission, PendingAppleAgreement, MissingIOSMembership, PendingGooglePlayKey.

🕰️
get_stale_apps
READ

Apps not updated within a configurable threshold (default 180 days), filterable by type and platform.

🏗️
get_build_queue
READ

Live CI build queue state — ReadyToBuild, Building, Built, Failed — for iOS or Android via Admin API.

📊
query_apps
READ

Flexible AND-filter report across version, CBA status, App Store state, iOS membership, app type, and business.

🔐
check_cert_validity
READ

Apple push cert and provisioning profile check. Single-app or bulk scan with expiry threshold. Sorted by severity.

⚡
trigger_app_build
ACTION

Trigger an iOS or Android build on Bitrise or Jenkins. Returns build ID and queue URL. (Phase 4)

How it works

From zero to querying in 4 steps

STEP 01
📦
Clone & Install

Clone the repo and run npm install. Requires Node.js 20+.

STEP 02
⚙️
Configure .env

Copy .env.example to .env and fill in AWS, Admin Panel, and Bitrise credentials.

STEP 03
🔨
Build

Run npm run build to compile TypeScript to an optimised ESM bundle in dist/.

STEP 04
🤖
Connect Agent

Add the mcp.json snippet to Cursor or Claude Desktop and supply your ADMIN_PANEL_API_KEY.

Integration

One config block, any agent

Works with every MCP client

CBA-MCP supports both stdio (local) and HTTP (remote) transports. Connect once, query from any agent that speaks MCP.

The only credential each user needs is their own ADMIN_PANEL_API_KEY — all server-side infrastructure credentials are pre-loaded from .env.

Cursor Claude Desktop Claude.ai OpenAI Agents SDK LangChain n8n MCP Inspector VS Code Copilot
~/.cursor/mcp.json 
{
  "mcpServers": {
    "cba-mcp": {
      "command": "npm",
      "args": [
        "--prefix",
        "/path/to/cbfa-mcp",
        "start"
      ],
      "env": {
        "ADMIN_PANEL_API_KEY":
          "your-api-key"  ← only this
      }
    }
  }
}
